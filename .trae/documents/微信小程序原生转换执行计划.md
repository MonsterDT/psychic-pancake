## 四、假设与决策

### 4.1 关键决策

| 决策项 | 选择 | 理由 |
|---|---|---|
| 转换方式 | 完整原生转换 | 用户明确选择，非web-view |
| 图片资源 | 保留 trae API URL | urlCheck已关闭，dev环境可加载；正式上线再替换CDN |
| SVG图标 | 转为`<image>`引用 | 小程序不支持内联SVG；统一用image+iconfont方案 |
| Modal系统 | 全屏modal→navigateTo独立页；底部sheet→自定义组件 | 全屏modal在小程序中更适合用页面承载 |
| Tinder滑动 | `movable-view`组件 | 原生支持拖拽，性能优于自定义touch |
| 数据双源 | data.js中保留libraryFeed+makeupLibraryData，findTemplateById同时搜索 | 遵循项目memory约束 |
| localStorage | wx.setStorageSync同步API | 与原localStorage同步行为一致 |
| 自定义tabBar | 是 | 中间"焕新"按钮需突出样式，原生tabBar不支持 |

### 4.2 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 图片URL在dev工具中可能不显示 | 视觉缺失 | image-safe组件带binderror回退占位图 |
| 主包体积可能超2MB | 编译报错 | 按分包严格拆分，主包仅放5tab页+公共组件 |
| movable-view滑动体验差异 | 交互不一致 | 参考源demo阈值(20px)调优 |
| trae API域名非HTTPS | 请求被拦截 | dev工具urlCheck已关闭；正式需HTTPS域名 |
| 122个SVG转image工作量大 | 开发耗时 | 优先转换tab图标和高频图标，低频用文字/emoji替代 |
