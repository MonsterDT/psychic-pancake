## 架构决策

### 1. 弹窗→页面转换（9个）
原 demo 中的弹窗/浮层在小程序中转为独立页面（已在 app.json 中声明）：

| demo 中的形态 | 小程序页面 | 分包 |
|---|---|---|
| gp-center-modal（全屏弹窗） | packageD/pages/gp-center | flow |
| withdraw-modal（底部弹窗） | packageD/pages/withdraw | flow |
| recharge-modal（底部弹窗） | packageD/pages/recharge | flow |
| trending-modal（底部弹窗） | packageD/pages/trending | flow |
| companion-modal（全屏弹窗） | packageD/pages/companion-chat | flow |
| share-modal（底部弹窗） | packageD/pages/share | flow |
| mirror-settings-modal（弹窗） | packageD/pages/mirror-settings | flow |
| face-auth-overlay（全屏浮层） | packageD/pages/face-auth | flow |
| onboarding-overlay（全屏浮层） | packageD/pages/onboarding | flow |

### 2. SVG 图标处理
微信小程序 WXML 不支持内联 `<svg>`。采用方案：
- 简单图标（箭头、关闭、爱心等）→ **WXSS 伪元素 + base64 data URI** 写入 `styles/icons.wxss`
- 复杂图标 → 使用 emoji 或 `<image>` 标签 + base64
- 按需转换，不为所有 122 个 SVG 创建资源文件

### 3. 图片域名配置
所有图片使用 `https://trae-api-cn.mchost.guru/api/ide/v1/text_to_image?prompt=...`。
- `project.config.json` 已设置 `urlCheck: false`（开发时不校验域名）
- 正式发布需在小程序后台配置 downloadFile 域名白名单
- 组件 `image-safe` 统一处理图片加载，失败时显示占位图

### 4. CSS 适配规则
- `:root` → `page` 选择器（已完成）
- `env(safe-area-inset-*)` → JS 计算后通过内联样式注入（`app.js` 已获取 safeTop/safeBottom）
- `px` 单位保留（不转 rpx），因 demo 设计基于 375px 宽度
- `position: fixed` → 小程序中 fixed 相对屏幕，需注意 tabBar 遮挡
- `backdrop-filter` → 小程序不支持，用 `rgba` 背景替代
- `scroll-behavior: smooth` → 使用 `scroll-view` 的 `scroll-into-view` 属性

### 5. 数据流
- **全局状态**（用户信息、GP余额、购物车数量）→ `app.globalData`
- **持久化数据**（购物车、收藏、搜索历史）→ `wx.storage`（已封装 `utils/storage.js`）
- **页面间传参** → URL query 参数（`navigateTo` 的 `url`）
- **跨页事件通知** → `EventChannel`（`wx.navigateTo` 的 `events` 参数）或 `app.globalData` 轮询

### 6. 登录验证
使用多重检查（已封装 `utils/auth.js`）：
```js
isLoggedIn() = storage.get('isLoggedIn') || storage.get('userName') || app.globalData.gpBalance > 0
```

## 风险评估

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 图片域名未配置 | 图片无法加载 | `urlCheck: false` 开发模式跳过；提供域名白名单配置说明 |
| movable-view 性能 | Tinder卡片滑动卡顿 | 限制同时渲染3张卡片，使用 CSS transform 硬件加速 |
| 分包体积超限 | 编译失败 | 主包<2MB，单分包<1.5MB；图片走网络不占包体积 |
| camera 组件兼容性 | 部分机型不支持 | 提供相册选图降级方案；开发者工具模拟 |
| 自定义 tabBar 与原生冲突 | 角标不更新 | 在 tab 页 onShow 中手动同步角标状态 |
| SVG 转换遗漏 | 图标显示空白 | 使用 emoji 降级 + base64 关键图标 |
| 工作量巨大 | 单次会话无法完成 | 分阶段提交，每阶段可独立编译运行 |
