# 妆伴 MakeupPal 项目展示平台 PRD

## 1. 项目概述

### 1.1 项目背景
妆伴 MakeupPal 是一款面向亚洲女性的智能美妆助手 Web 应用（V3.6.0），融合妆容推荐、教程学习、虚拟试妆、商品购买的一站式美妆体验平台。本项目展示平台（Showcase）旨在以专业、视觉化的方式全面呈现 MakeupPal 的核心功能、技术架构、设计理念与成果价值，用于 trae 大赛评审、投资路演、团队展示等场景。

### 1.2 目标
- **专业呈现**：以高端美妆品牌视觉语言展示项目全貌
- **交互演示**：嵌入可交互的 demo，让评审直接体验产品
- **技术透明**：清晰展示多端架构、技术栈、创新点
- **数据可视化**：用图表直观呈现项目规模、功能覆盖、迭代历程
- **响应式适配**：桌面/平板/手机均完美展示

### 1.3 目标用户
| 用户 | 场景 |
|------|------|
| 大赛评审 | 快速了解项目全貌、技术亮点、创新性 |
| 投资人 | 评估产品价值、市场潜力、团队实力 |
| 团队成员 | 对外展示项目成果 |
| 技术社区 | 学习架构设计与技术方案 |

## 2. 展示平台模块设计

### 2.1 导航结构
顶部固定导航栏（毛玻璃效果），包含：
- Logo「妆伴 MakeupPal」
- 锚点导航：概述 / 功能 / 架构 / 特性 / 场景 / 数据 / 团队
- CTA 按钮「体验 Demo」

### 2.2 模块清单

| # | 模块 | 内容 | 视觉重点 |
|---|------|------|----------|
| 1 | **Hero 首屏** | 项目名称、Slogan、核心数据（7模块/3端/43页面/V3.6.0）、CTA | 全屏渐变背景 + 品牌装饰 + 动画入场 |
| 2 | **项目概述** | 项目定位、产品愿景、解决的用户痛点、目标用户画像（6类） | 左右分栏：文字 + 用户画像卡片网格 |
| 3 | **功能演示** | 7大功能模块展示（首页/颜库/焕新/市集/我的/美妆闺蜜AI/成分扫描）+ 可交互 demo 嵌入 | 模块卡片网格 + iframe 实时演示 |
| 4 | **技术架构** | 多端架构图（Web H5 / 微信小程序 / 鸿蒙）、技术栈分层、数据流 | 架构图 + 技术栈标签云 |
| 5 | **关键特性** | 8大创新点（Tinder滑动/小美AI/统一数据源/回看/成分扫描/玫瑰金设计/多端/隐私） | 卡片轮播或网格 + 图标 |
| 6 | **使用场景** | 6类用户场景案例（新手/职场/爱好者/敏感肌/银发族/达人） | 场景故事卡片 + 用户旅程 |
| 7 | **成果数据** | 项目规模数据可视化（版本迭代时间线、功能模块占比、代码量、页面数） | ECharts 图表（时间线/雷达图/柱状图） |
| 8 | **团队介绍** | 团队成员、角色分工、联系方式 | 团队卡片 + 社交链接 |
| 9 | **Footer** | 版权信息、技术栈、链接 | 简洁页脚 |

### 2.3 交互设计
- **滚动动画**：各模块进入视口时淡入上移（IntersectionObserver）
- **导航高亮**：当前滚动位置对应的导航项高亮
- **Demo 嵌入**：iframe 加载 makeuppal-demo-v3.6.0.html，支持实时交互
- **图表交互**：ECharts 图表悬停显示数据详情
- **响应式**：移动端导航折叠为汉堡菜单

## 3. 视觉设计规范

### 3.1 色彩系统
```css
--primary: #C4956A;          /* 玫瑰金主色 */
--primary-light: #D4B08A;    /* 浅玫瑰金 */
--primary-lighter: #E8D5C0;  /* 更浅 */
--primary-lightest: #F5EDE4; /* 最浅 */
--primary-dark: #A87D56;     /* 深玫瑰金 */
--bg: #FBF6F0;               /* 暖白背景 */
--bg-card: #FFFFFF;          /* 卡片白 */
--text: #2D2A26;             /* 主文字 */
--text-secondary: #6B6560;   /* 次要文字 */
--text-muted: #9E9790;       /* 弱化文字 */
--accent: #E8B4B8;           /* 粉色点缀 */
--success: #7FB069;          /* 成功绿 */
```

### 3.2 字体
- **标题**：Noto Serif SC（衬线体，优雅品牌感）
- **正文**：Plus Jakarta Sans（现代无衬线，可读性好）
- **数字**：Plus Jakarta Sans（等宽数字特性）

### 3.3 间距与圆角
- 卡片圆角：16px（中）/ 24px（大）
- 阴影：分层阴影（sm/md/lg），玫瑰金色调
- 间距：8px 基准网格

### 3.4 背景氛围
- 固定径向渐变光斑（右上 + 左下）
- 各模块交替使用浅色/白色背景
- Hero 区域使用动态渐变 + 装饰圆环

## 4. 技术实现

### 4.1 文件结构
```
showcase.html    # 单文件展示平台（HTML + CSS + JS 内联）
```

### 4.2 技术选型
| 功能 | 方案 |
|------|------|
| 布局 | 原生 CSS Flexbox + Grid |
| 动画 | CSS Animation + IntersectionObserver |
| 图表 | ECharts（本地 _shared/echarts.min.js） |
| Demo 嵌入 | iframe 加载 makeuppal-demo-v3.6.0.html |
| 字体 | Google Fonts（Noto Serif SC + Plus Jakarta Sans） |
| 图标 | 内联 SVG + Emoji |

### 4.3 响应式断点
| 断点 | 适配 |
|------|------|
| ≥1024px | 桌面（完整布局） |
| 768-1023px | 平板（2列网格） |
| <768px | 手机（单列 + 汉堡菜单） |
