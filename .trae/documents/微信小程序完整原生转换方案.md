# MakeupPal v3.6.0 微信小程序完整原生转换方案

## Context（背景）

当前 `makeuppal-demo-v3.6.0.html` 是一个 898KB 的单页 HTML 应用（22,798行），包含 32 个页面、239 个函数、462 个 onclick 事件、265 处 DOM 操作。用户要求将其**完整原生转换**为微信小程序代码，单独建立 `makeuppal-miniprogram/` 文件夹，并同步提交到 GitHub。

核心挑战：HTML 的"命令式 DOM 操作"模式需全面重构为小程序的"数据驱动声明式渲染"模式。

## 项目目录结构

新建 `makeuppal-miniprogram/`，采用主包+分包结构（参照既有 `harmonyos/` 独立目录范式）：

```
makeuppal-miniprogram/
├── project.config.json / app.json / app.js / app.wxss / sitemap.json
├── assets/           # icons(tabBar PNG) + iconfont(200+SVG统一) + images
├── components/       # 13个公共组件(image-safe/modal/face-slim-card/template-card等)
├── utils/            # 9个工具模块(storage/router/scene/recommend/auth/clipboard等)
├── data/             # 11个数据模块(从MakeupPalData拆出)
├── styles/           # variables.wxss + mixins.wxss + animations.wxss
├── pages/            # 主包5个tab页(home/library/mirror/mall/profile)
├── packageA/         # 分包:交易链路(8页:商品详情/购物车/订单/地址等)
├── packageB/         # 分包:颜库详情(9页:模板详情/面部档案/日记等)
├── packageC/         # 分包:创作者(10页:创作者中心/上传/收益/学院等)
├── packageD/         # 分包:特殊流程(11页:AI聊天/扫描/引导/分享等)
└── custom-tab-bar/   # 自定义tabBar(中间焕新按钮突出样式)
```

## 关键技术难点解决方案

### 1. Tinder卡片滑动（最复杂）

* **方案**：`<movable-view direction="horizontal">` + 数据驱动

* `bindchange`实时获取x坐标，同步like/dislike badge透明度

* 阈值20px（与源码`tinderSwipeThreshold`一致）

* `catchtap`区分点击与滑动（cardX===0时为点击）

* 450ms动画飞出，堆叠效果用z-index+scale+translateY

### 2. AI聊天数据驱动

* **方案**：messages数组 + `wx:for`渲染 + `scroll-into-view`自动滚底

* `generateRecommendationCards`从返回HTML改为返回`{templates:[],products:[]}`数据结构

* 800ms setTimeout模拟AI思考

### 3. 200+ SVG图标统一

* tabBar图标（5对=10个）：SVG→PNG转换（小程序tabBar限制）

* 页面内200+SVG：iconfont字体方案（体积最优）

* emoji图标：wxml直接支持

### 4. 14套弹窗系统统一

* 复杂全屏弹窗（6个）→转独立页面（navigateTo）

* 简单底部抽屉（3个）→`<bottom-sheet>`组件

* 结果展示（3个）→`<modal>`组件

* 分享→`wx.showShareMenu`原生

* Toast→`wx.showToast`原生
