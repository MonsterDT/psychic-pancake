### 已建立的技术模式（执行时严格遵循）

- **模块系统**：CommonJS（`module.exports` / `require()`），禁用 ES6 import/export
- **组件构造器**：`Component({ options: { styleIsolation: 'apply-shared' } })`
- **图片系统**：`const { getImageUrl } = require('../../data/images')`，所有图片走 `trae-api-cn.mchost.guru`，project.config.json 已设 `urlCheck: false`
- **图片组件**：使用 `<image-safe src="..." />` 组件，自动处理 URL/key/assets 路径
- **存储**：`const storage = require('../../utils/storage')`，封装 `wx.storage`
- **路由**：`const router = require('../../utils/router')`，提供 `navigateTo/switchTab/openXxx` 辅助函数
- **常量**：`const { LIBRARY_CATS, MARKET_CATS, STORAGE_KEYS, COMPANION_NAME } = require('../../utils/constants')`
- **CSS 变量**：已定义在 `page` 选择器（70+ 变量），WXSS 直接 `var(--xxx)` 使用
- **SVG 替代**：WXML 中不写内联 SVG，用 emoji + CSS 伪元素（见 styles/icons.wxss）

## 三、拟定变更（Proposed Changes）

### Phase 3：5 个主 Tab 页（核心里程碑 · 首个可测试节点）

每页 4 文件（.wxml/.wxss/.js/.json）。实现后即可在开发者工具编译运行，作为首个测试里程碑。

#### 3.1 首页 `pages/home/`
- **数据源**：`faceProfileData`（face-profile.js）、`banners`（banners.js）、`libraryFeed.creators`（library.js）
- **WXML 结构**（对照 demo 行 10773-11065）：
  1. 面部档案卡片（compact，点击 → `router.openFaceProfile()`）
  2. 美妆闺蜜问候卡（点击 → `router.openCompanionChat()`）
  3. 金刚位 5 宫格（🪞魔镜/🔍局部搜索/🛍️市集/🔬成分扫描/✨创作者）
  4. Banner 轮播（`<swiper>` 自动播放，4 张，点击跳转）
  5. 本周热门（横向 `scroll-view`，热门榜单卡片，点击 → `router.openTemplateDetail(id)`）
  6. 达人精选预览（3 卡片 + "查看更多" → `router.switchTab('library')`）
- **JS 逻辑**：onLoad 读 globalData.user，轮播自动切换，跳转用 router
- **json**：`{ "usingComponents": { "image-safe": "/components/image-safe/image-safe", "companion-fab": "/components/companion-fab/companion-fab" }, "navigationBarTitleText": "妆伴" }`

#### 3.2 颜库 `pages/library/`
- **数据源**：`libraryFeed` + `libraryExtraData`（library-extra.js），`LIBRARY_CATS`
- **核心交互**：卡片模式（Tinder 风格滑动）+ 瀑布流模式切换
- **WXML 结构**（对照 demo 行 11131-11212）：
  1. 顶部：类目栏（7 类目横向滚动）+ 模式切换按钮（卡片/瀑布流图标）
  2. 卡片模式：`<movable-view>` 实现左右滑动（20px 阈值，450ms 动画），喜欢/不喜欢按钮
  3. 瀑布流模式：子类目栏显示，双列 `scroll-view` 瀑布流
  4. 喜欢按钮 → `storage.addFavoriteTemplate(id)`（多重登录验证：isLoggedIn/userName/gpBalance）
- **JS 关键**：`getLibraryItems(cat, sub)` 统一数据接口、`initTinderCards()`、`onMovableChange()` 滑动判定
- **约束**（来自 project_memory）：卡片模式子类目栏 `display:none`；喜欢/不喜欢按钮 `position:fixed` 底部，`bottom: calc(var(--tab-bar-height) + var(--safe-bottom) + 10px)`

#### 3.3 焕新 `pages/mirror/`
- **数据源**：`faceProfileData`、当前妆容状态（localStorage）
- **WXML 结构**（对照 demo 行 11213-11336）：
  1. `<camera>` 组件作为魔镜背景（无相机权限时降级为图片）
  2. 顶部：试妆模式切换（AI魔镜/教程跟练/前后对比）
  3. 底部：妆容步骤导航 + 产品清单
  4. 浮动入口：美妆闺蜜（`<companion-fab>`）
- **JS 关键**：`wx.createCameraContext()`、`wx.authorize({ scope: 'scope.camera' })`
- **约束**：不含原对话功能开关入口，引导用浮窗

#### 3.4 市集 `pages/mall/`
- **数据源**：`marketProducts`（products.js）、`MARKET_CATS`、`marketSubcats`
- **WXML 结构**（对照 demo 行 11337-11417）：
  1. 顶部：搜索栏（点击 → `router.openSearch()`）+ 购物车/订单图标（带角标）
  2. 分类横栏（6 类目：口红/底粉/眼影/腮红/小面/护肤）
  3. 子分类栏（新品上市/限时特惠/爆款推荐/礼盒套装/小样试用）
  4. 商品瀑布流网格（`<product-card>` 组件，点击 → `router.openProductDetail(id)`，加购 → `storage.addToCart()`）
- **JS 关键**：`getMarketProducts(cat, sub)`、分类切换、购物车角标更新
- **约束**：购物车/订单按钮替换原分类筛选按钮位置

#### 3.5 我的 `pages/profile/`
- **数据源**：globalData（userName/gpBalance）、storage（收藏/地址/订单）
- **WXML 结构**（对照 demo 行 11853-12008）：
  1. 用户信息卡（头像+昵称+焕新值 GP，点击 GP → `router.openGpCenter()`）
  2. 订单状态 5 宫格（待付款/待发货/待收货/已完成/退款）
  3. 功能网格（profile-grid-5）：我的模板/我的报告/地址管理/优惠券/创作者中心
  4. 🌸 小美设置入口（profile-grid-5 独立模块）
  5. 设置列表（风格偏好/门店地图/消息中心/邀请好友/关于）
- **JS 关键**：读 globalData 显示 GP，跳转各功能页
