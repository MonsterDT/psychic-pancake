2.1Step 1：注册前调研（Pre-Registration Survey）

设计目的

在用户注册前收集关键偏好数据，降低注册流失率。通过快速选择题让用户在 30 秒内完成调研，预填面部资产库的肤质字段并实现个性化首页推荐。

调研内容（4 题快速选择题）

题号问题选项数据用途
1/4 你最想解决的美妆问题？ 局部卡点 / 全脸不会画 / 产品踩雷 / 想学国风妆 首页推荐内容分类
2/4 你的化妆经验？ 完全新手 / 有一定基础 / 比较熟练 教程难度推荐 + 引导文案调整
3/4 你的肤质？ 油皮 / 干皮 / 混合 / 敏感 预填面部资产库肤质字段 + 产品推荐过滤
4/4 你最关注的场景？ 通勤 / 约会 / 聚会 / 旅行 / 日常 首页推荐场景 + 妆容模板推荐

交互设计

每题一屏

每道题单独一屏，避免信息过载。用户只需点击一个选项即可进入下一题，操作极简。

大按钮选择

选项以大按钮形式展示（最小触控区域 56x56dp），文字清晰，适合单手操作。选中状态有明显的视觉反馈（玫瑰金高亮边框）。

进度条显示

顶部进度条实时显示当前进度（1/4 → 2/4 → 3/4 → 4/4），让用户有明确的完成预期。进度条采用渐变色填充（奶油 → 玫瑰金）。

耗时约 30 秒

4 道题 + 页面切换动画，总耗时约 30 秒。目标：调研完成率 > 90%。

设计要点：调研在注册前进行，用户无需登录即可完成。调研数据暂存本地，注册成功后自动同步至服务端。即使调研后未注册，数据仍可用于匿名个性化推荐（降低注册摩擦）。

2.2Step 2：基础信息收集 + 注册（Profile Setup）

注册方式

手机号 + 验证码注册

标准注册方式。输入手机号 → 获取验证码（60 秒倒计时）→ 输入验证码 → 注册成功。验证码 6 位数字，有效期 5 分钟。

HarmonyOS 账号一键登录

优先推荐方式。调用 HarmonyOS Account Kit 一键授权登录，无需手动输入手机号和验证码。降低注册摩擦，提升转化率。

基础信息收集

信息项是否必填选项/格式说明
昵称 必填 2-12 个字符 默认生成随机昵称，用户可修改
头像 可选 拍照 / 相册 / AI 生成卡通头像 AI 生成卡通头像基于昵称 + 偏好风格
年龄段 必填 18-25 / 26-30 / 31-35 / 36-45 / 46+ 大按钮选择，单选
风格偏好标签 可选 自然清新 / 精致优雅 / 甜美可爱 / 国风古韵 / 欧美气场 可多选（最多 3 个），影响首页推荐

注册奖励

注册完成自动发放 100 GP 首次注册奖励。奖励以动画形式展示（金币飞入效果），让用户产生"资产感"。GP 余额实时显示在首页顶部，强化用户对虚拟资产的感知。
防刷机制：同一设备 ID + 同一手机号仅限领取一次注册奖励。HarmonyOS 账号登录的用户，以 HarmonyOS 账号 ID 为唯一标识。

2.3Step 3：首次面部扫描（First Face Scan）

引导文案

"让我们认识你的脸，为你生成专属美妆方案"

扫描流程

HMS AR Engine 端侧扫描

调用 HMS AR Engine 的 3D 面部扫描能力，在端侧完成面部数据采集。扫描耗时 15-30 秒，需要用户正对摄像头，缓慢左右转头。全程在端侧处理，不上传原始面部数据至云端（隐私安全）。

扫描引导动画

扫描过程中显示引导动画：面部轮廓线 + 扫描进度环。引导用户调整角度（正面 → 左转 → 右转），确保采集全面。扫描完成后显示"扫描成功"动画。

四维分析结果

扫描完成后展示四维分析结果，每项以卡片形式呈现：

维度分析内容可选值数据用途
脸型 面部轮廓形状分析 圆脸 / 方脸 / 瓜子脸 / 长脸 / 菱形脸 妆容风格推荐 + 效果图适配
肤色 肤色色调分析 冷白 / 暖黄 / 自然 / 橄榄 底妆色号推荐 + 口红色系推荐
肤质 皮肤油脂分泌分析 油皮 / 干皮 / 混合 / 敏感 产品推荐过滤 + Step 1 调研数据交叉验证
骨相特征 面部骨骼结构分析 高颧骨 / 平颧骨 / 深眼窝 / 浅眼窝等 修容方案推荐 + 高光位置建议
扫描完成奖励 +20 GP。奖励以动画形式展示，与注册奖励叠加。此时用户 GP 余额为 120 GP（注册 100 + 扫描 20），为下一步 AI 渲染消耗 50 GP 做好铺垫。
隐私安全：面部扫描数据仅存储在用户设备端侧，云端仅存储分析结果（脸型/肤色/肤质/骨相标签），不存储原始面部图像。用户可随时在设置中删除面部数据。

2.4Step 4：选择妆造风格 + AI 渲染（Style Selection + AI Render）

智能推荐逻辑

基于 Step 1 调研数据（美妆问题 + 经验 + 肤质 + 场景）+ Step 3 面部数据（脸型 + 肤色 + 骨相），智能推荐 3 个最适合的妆容风格。推荐算法复用 F2 AI 妆造渲染的意图解析引擎。

风格推荐卡片

展示 3 个推荐妆容风格，每个风格卡片包含：

卡片元素内容说明
效果图缩略图 该风格的示例效果图 使用与用户脸型相似的效果图，增强代入感
风格名称 如"甜美约会妆"、"通勤气质妆" 简洁明了，突出场景感
适合理由 如"你的圆脸很适合这款甜美约会妆" 个性化推荐理由，增强信任感

AI 渲染流程

用户选择风格

用户点击一个风格卡片 → 触发 AI 渲染。渲染前弹出确认弹窗："即将消耗 50 GP 为你生成专属妆容效果"，显示当前 GP 余额（120 GP），强调"免费体验"。

渲染过程展示

3-5 秒加载动画 + 进度提示。动画内容：素颜照片 → 逐步叠加妆容效果（底妆 → 眉毛 → 眼妆 → 唇妆 → 完成）。让用户感知 AI 正在"认真工作"。

Before/After 对比

渲染完成后展示 Before（素颜）→ After（上妆效果）对比图。支持左右滑动对比、一键切换 Before/After。这是整个 Onboarding 的"Wow Moment"。

保存到相册

"太美了！保存到相册"按钮 — 保存触发 Step 5 会员转化弹窗。同时支持"再试一个风格"（消耗额外 50 GP）和"跳过"。

GP 消耗逻辑：AI 渲染消耗 50 GP，从注册奖励 100 GP + 扫描奖励 20 GP 中扣除。用户实际感知为"免费体验"（因为使用的是赠送的 GP），降低心理门槛。渲染完成后 GP 余额为 70 GP。

转化成功后流程

欢迎加入 Premium

显示"欢迎加入 Premium"成功页，包含 Premium 标识动画 + 权益概览。自动发放 200 GP 月度赠送（此时 GP 余额为 70 + 200 = 270 GP）。

引导进入镜面模式

成功页底部显示"立即体验镜面模式"按钮，引导用户进入 F6 镜面交互模式，体验核心差异化功能。这是 Premium 用户留存的关键入口。

2.6跳过策略 + 二次触达

跳过后的处理

行为处理方式说明
本次会话不再弹出 设置 session-level flag 本次会话内不再弹出付费弹窗，避免打扰
首页显示 Premium 入口横幅 "限时：首月 ¥19" 非侵入式提醒，用户可随时点击开通
3 天后可再次弹出 软提醒弹窗 3 天后首次打开 App 时弹出，文案更温和

二次触达策略

3 天软提醒弹窗

文案："你上次生成的妆容效果还在哦，开通 Premium 解锁更多风格"。复用 Step 4 的渲染结果作为弹窗配图，唤起用户记忆。

首页 Premium 横幅

跳过后首页顶部显示横幅："限时：首月 ¥19 开通 Premium"。横幅可关闭，关闭后 24 小时内不再显示。横幅文案根据用户行为动态调整。

GP 余额不足提醒

当用户 GP 余额不足以支付下次 AI 渲染时，弹出"GP 不足"提示 + Premium 开通引导。自然场景触发，非强制弹窗。

二次触达原则：不强制付费，跳过后用户仍可正常使用基础功能（含免费 AI 渲染，消耗 GP）。二次触达以"温和提醒"为主，避免负面体验。目标：给犹豫用户第二次机会，同时不骚扰已明确拒绝的用户。

转化策略要点

6 条核心转化策略，驱动 Premium 转化率 > 12%。

4转化策略要点（6 条核心策略）

1先给甜头 — 注册送 100 GP + 扫描送 20 GP

用户在注册和面部扫描两个关键节点分别获得 GP 奖励，让用户产生"资产感"。GP 余额实时显示在首页顶部，强化虚拟资产感知。用户潜意识中会认为"这些 GP 是我的"，不愿浪费，从而增加使用频率和付费意愿。

2制造惊喜 — AI 渲染是 Wow Moment

AI 渲染的 Before/After 对比图是整个 Onboarding 的"Wow Moment"。用户看到自己素颜变上妆的惊艳效果，会产生强烈的情感冲击和付费意愿。这是转化弹窗的触发时机——在情绪最高点弹出付费弹窗。

3精准时机 — 情绪最高点弹出付费弹窗

付费弹窗在用户保存渲染结果后自动弹出，此时用户刚刚看到美丽的 Before/After 对比图，情绪处于最高点。弹窗复用渲染结果作为配图，强化"这是你专属的美丽效果"的感知。

4无感消耗 — 渲染消耗 50 GP 从奖励中扣除

AI 渲染消耗 50 GP，从注册奖励 100 GP + 扫描奖励 20 GP 中扣除。用户实际感知为"免费体验"，因为使用的是赠送的 GP。渲染前弹窗明确显示 GP 余额，强调"免费体验"，降低心理门槛。

5可跳过 — 不强制付费，避免负面体验

付费弹窗提供明确的"跳过"按钮，不强制付费。跳过后用户仍可正常使用基础功能（含免费 AI 渲染），避免因强制付费导致的负面体验和卸载。可跳过策略是长期用户留存的基础。

6二次触达 — 3 天后软提醒 + 首页横幅

跳过后不放弃转化机会。3 天后弹出软提醒弹窗（文案更温和，复用渲染结果唤起记忆），首页显示 Premium 入口横幅（"限时：首月 ¥19"），GP 余额不足时自然触发开通引导。给犹豫用户第二次机会。

策略总结：6 条策略形成完整的转化闭环——先给甜头建立资产感 → 制造惊喜激发付费意愿 → 精准时机弹出付费弹窗 → 无感消耗降低心理门槛 → 可跳过保护用户体验 → 二次触达挽回犹豫用户。每一步都经过精心设计，确保转化率最大化。

5.1 onboarding_sessions（引导会话表）

CREATE TABLE onboarding_sessions (
    session_id      BIGSERIAL PRIMARY KEY,
    user_id         BIGINT,                         -- 用户 ID（注册后填充，注册前为 NULL）
    device_id       VARCHAR(100) NOT NULL,           -- 设备 ID（用于未注册用户追踪）
    step1_completed BOOLEAN DEFAULT FALSE,            -- Step 1 调研完成
    step1_answers   JSONB,                           -- 调研答案：{q1, q2, q3, q4}
    step1_duration  INTEGER,                         -- Step 1 耗时（毫秒）
    step2_completed BOOLEAN DEFAULT FALSE,            -- Step 2 注册完成
    step2_login_method VARCHAR(30),                  -- 登录方式：phone/harmonyos
    step2_nickname  VARCHAR(50),                     -- 昵称
    step2_age_group VARCHAR(20),                     -- 年龄段
    step2_style_tags JSONB,                         -- 风格偏好标签
    step2_duration  INTEGER,                         -- Step 2 耗时（毫秒）
    step3_completed BOOLEAN DEFAULT FALSE,            -- Step 3 面部扫描完成
    step3_face_shape VARCHAR(30),                   -- 脸型分析结果
    step3_skin_tone  VARCHAR(30),                    -- 肤色分析结果
    step3_skin_type  VARCHAR(30),                    -- 肤质分析结果
    step3_bone_features JSONB,                       -- 骨相特征
    step3_duration  INTEGER,                         -- Step 3 耗时（毫秒）
    step4_completed BOOLEAN DEFAULT FALSE,            -- Step 4 AI 渲染完成
    step4_selected_style VARCHAR(100),               -- 选择的风格
    step4_render_id  BIGINT,                         -- 渲染结果 ID（关联 F2）
    step4_gp_cost    INTEGER DEFAULT 50,              -- 消耗 GP 数量
    step4_duration  INTEGER,                         -- Step 4 耗时（毫秒）
    step5_shown     BOOLEAN DEFAULT FALSE,            -- Step 5 付费弹窗是否展示
    step5_result    VARCHAR(20),                     -- 弹窗结果：converted/skipped
    step5_skip_reason VARCHAR(50),                  -- 跳过原因（可选）
    total_duration  INTEGER,                         -- 总耗时（毫秒）
    status          VARCHAR(20) DEFAULT 'active',    -- 状态：active/completed/abandoned
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);

-- 索引
CREATE INDEX idx_onboarding_user ON onboarding_sessions(user_id);
CREATE INDEX idx_onboarding_device ON onboarding_sessions(device_id);
CREATE INDEX idx_onboarding_status ON onboarding_sessions(status);

5.2 conversion_funnel（转化漏斗表）

CREATE TABLE conversion_funnel (
    funnel_id       BIGSERIAL PRIMARY KEY,
    session_id      BIGINT REFERENCES onboarding_sessions(session_id),
    user_id         BIGINT,
    step_number     SMALLINT NOT NULL,              -- 步骤编号：1-5
    step_name       VARCHAR(50) NOT NULL,           -- 步骤名称：survey/register/scan/render/premium
    event_type      VARCHAR(30) NOT NULL,            -- 事件类型：start/complete/skip/error
    triggered_at    TIMESTAMP DEFAULT NOW(),         -- 触发时间
    duration_ms     INTEGER,                         -- 步骤耗时（毫秒）
    extra_data      JSONB,                           -- 额外数据
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 索引
CREATE INDEX idx_funnel_session ON conversion_funnel(session_id);
CREATE INDEX idx_funnel_user ON conversion_funnel(user_id);
CREATE INDEX idx_funnel_step ON conversion_funnel(step_number, event_type);
CREATE INDEX idx_funnel_date ON conversion_funnel(triggered_at);
数据表说明：onboarding_sessions 记录每步完成状态、耗时、选择结果，是 Onboarding 流程的核心数据表。conversion_funnel 记录漏斗每步的转化数据，用于转化率分析和漏斗优化。两张表通过 session_id 关联。

事件名触发时机参数说明
