# 生命导航 — UI 设计规范

> 温暖治愈系 · Warm Healing Design System
> 版本 1.0 · 2026.06

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **温暖安全感** | 暖色调为主，圆角柔和，大量留白，营造安全可信赖的氛围 |
| **清晰层级** | 统一的"奶油底 + 白卡片 + 细边框"层级模型，不使用半透明/毛玻璃 |
| **单一品牌色** | 仅使用一个品牌主色（琥珀金），通过明暗变化表达层级，不引入额外的辅助色 |
| **信息优先** | 内容驱动设计，避免装饰性元素干扰核心交互 |

- **禁止**在静态卡片/列表上使用彩色阴影或发光效果
- 身份/类别区分仅通过文字、图标、中性色调、布局或品牌色的明暗来实现

## 3. 字体系统

### 3.1 字体族

| 用途 | 字体栈 |
|------|--------|
| **展示字体**（标题） | `'Noto Serif SC', Georgia, serif` |
| **正文字体**（UI/正文） | `'Noto Sans SC', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif` |

### 3.2 字号梯度

| Token | 大小 | rem | 典型用途 |
|-------|------|-----|----------|
| `--ln-font-size-4xl` | 36px | 2.25rem | H1（仅用于大标题） |
| `--ln-font-size-3xl` | 30px | 1.875rem | H2（页面主标题） |
| `--ln-font-size-2xl` | 24px | 1.5rem | H3（卡片标题） |
| `--ln-font-size-xl` | 20px | 1.25rem | H4（模块标题） |
| `--ln-font-size-lg` | 18px | 1.125rem | 大号正文 |
| `--ln-font-size-base` | 16px | 1rem | 标准正文 |
| `--ln-font-size-sm` | 14px | 0.875rem | 辅助文字、说明 |
| `--ln-font-size-xs` | 12px | 0.75rem | 标签、极小文字 |

### 3.3 字重

| Token | 值 | 用途 |
|-------|-----|------|
| `--ln-font-weight-bold` | 700 | H1、H2 标题 |
| `--ln-font-weight-semibold` | 600 | H3、H4、按钮 |
| `--ln-font-weight-medium` | 500 | 标签、强调 |
| `--ln-font-weight-normal` | 400 | 正文、说明 |

### 3.4 行高

| Token | 值 | 用途 |
|-------|-----|------|
| `--ln-line-height-tight` | 1.3 | 标题 |
| `--ln-line-height-normal` | 1.6 | 小标题、列表 |
| `--ln-line-height-relaxed` | 1.8 | 正文段落 |

### 3.5 排版类

| 类名 | 对应 | 说明 |
|------|------|------|
| `.ln-h1` | 衬线 36px/700/1.3 | 大标题 |
| `.ln-h2` | 衬线 30px/700/1.3 | 页面标题 |
| `.ln-h3` | 衬线 24px/600/1.6 | 卡片标题 |
| `.ln-h4` | 无衬线 20px/600/1.6 | 模块标题 |
| `.ln-body` | 无衬线 16px/400/1.8 | 正文 |
| `.ln-caption` | 无衬线 14px/400/1.6 | 辅助说明 |
| `.ln-label` | 无衬线 12px/500/1.6 大写 | 标签 |

### 3.6 标题规则

- 中文标题在 `text-xl` 及以上不超过 8 个汉字
- 标题使用名词短语，不使用完整句子
- CTA/按钮标签中文 2-6 字，英文 1-3 词

## 4. 间距系统

| Token | 值 | 典型用途 |
|-------|-----|----------|
| `--ln-space-xs` | 4px | 微小间距 |
| `--ln-space-sm` | 8px | 元素内间距 |
| `--ln-space-md` | 16px | 标准模块间距 |
| `--ln-space-lg` | 24px | 页面水平内边距 |
| `--ln-space-xl` | 32px | 大间距 |
| `--ln-space-2xl` | 48px | 区块间距 |
| `--ln-space-3xl` | 64px | 大区块间距 |

### 页面布局间距

- 页面水平内边距：`24px`（`px-6`）
- 卡片内边距：`20px`（`p-5`）
- 卡片之间间距：`12-16px`
- 底部安全区域：`pb-24`（为底部导航栏预留）

## 5. 圆角系统

| Token | 值 | 用途 |
|-------|-----|------|
| `--ln-radius-sm` | 6px | 小元素（标签、小按钮） |
| `--ln-radius-md` | 10px | 中等元素 |
| `--ln-radius-lg` | 14px | 卡片（主要圆角） |
| `--ln-radius-xl` | 16px | 大卡片 |
| `--ln-radius-full` | 9999px | 药丸按钮、圆形元素 |

### 圆角使用规范

- 所有卡片统一使用 `rounded-xl`（16px）或 `rounded-lg`（14px）
- 按钮使用 `rounded-full`（药丸形）或 `rounded-lg`
- 进度条、滑块轨道使用 `rounded-full`
- **禁止**使用 `rounded-2xl`（24px）以上的圆角

## 6. 阴影与深度

| Token | 值 | 使用场景 |
|-------|-----|----------|
| `--ln-shadow-sm` | `0 1px 3px rgba(45,42,36, 0.04)` | 微弱层次 |
| `--ln-shadow-md` | `0 2px 8px rgba(45,42,36, 0.05)` | 中等层次 |
| `--ln-shadow-lg` | `0 8px 24px rgba(45,42,36, 0.05)` | 较大层次 |
| `--ln-shadow-float` | `0 12px 40px rgba(45,42,36, 0.12)` | **仅浮层使用** |

### 深度规则

- **静态卡片/列表/表格/按钮/面板**：优先使用边框（`border: 1px solid var(--ln-color-border)`）表达层级
- 静态阴影 alpha 必须 `<= 0.05`
- **阴影 alpha > 0.05 仅允许浮层**：弹窗、下拉菜单、抽屉、提示框、吐司通知
- **禁止**彩色阴影、发光效果（glow）、neon 效果

## 7. 组件规范

### 7.1 卡片

**基础卡片**
```
背景: var(--ln-color-surface) (#FFFFFF)
边框: 1px solid var(--ln-color-border) (#E8DFD0)
圆角: 14-16px (rounded-xl / rounded-lg)
内边距: 20px (p-5)
阴影: 无（使用边框表达层级）
```

**选中态卡片**
```
边框: var(--ln-color-primary) (#C8860E) 1px solid
背景: var(--ln-color-primary-lightest) (#FFF8EB)
```

### 7.2 按钮

**主要按钮（Primary）**
```
背景: var(--ln-color-primary) (#C8860E)
文字: var(--ln-color-text-on-primary) (#FFFFFF)
圆角: var(--ln-radius-full) (药丸形)
内边距: 12px 24px
字体: --ln-font-size-sm (14px) / --ln-font-weight-semibold (600)
悬停: translateY(-1px) + 背景加深
按压: scale(0.99)
```

**幽灵按钮（Ghost）**
```
背景: transparent
边框: 1px solid var(--ln-color-border)
文字: var(--ln-color-text-secondary) (#6B6456)
悬停: 背景变为 var(--ln-color-surface-muted)
```

**禁用按钮**
```
背景: var(--ln-color-surface-muted) (#F9F3EA)
文字: var(--ln-color-text-tertiary) (#9E9586)
透明度: 0.5
光标: not-allowed
```

### 7.3 进度条

```
容器高度: 8px (h-2)
容器背景: var(--ln-color-surface-muted)
容器圆角: rounded-full
填充色: var(--ln-color-primary)
填充圆角: rounded-full
过渡: transition width var(--ln-transition-normal) (250ms)
```

### 7.4 标签/徽章

```
背景: var(--ln-color-primary-lightest) (#FFF8EB)
文字: var(--ln-color-primary-dark) (#A06C08)
圆角: var(--ln-radius-full)
内边距: 2px 12px
字号: var(--ln-font-size-xs) (12px)
```

### 7.5 评分圆点（生命平衡页）

**选中态**
```
背景: var(--ln-color-primary) (#C8860E)
文字: #FFFFFF
尺寸: 28x28px
圆角: rounded-full
```

**未选中态**
```
背景: var(--ln-color-surface) (#FFFFFF)
边框: 1px solid var(--ln-color-border) (#E8DFD0)
文字: var(--ln-color-text-tertiary) (#9E9586)
```

### 7.6 底部导航栏

```
位置: fixed bottom-0
背景: var(--ln-color-surface) (#FFFFFF)
顶部边框: 1px solid var(--ln-color-border)
内边距底部: env(safe-area-inset-bottom)
布局: justify-around, 4 个等宽标签
激活态颜色: var(--ln-color-primary) (#C8860E) + font-medium
非激活态颜色: var(--ln-color-text-tertiary) (#9E9586)
标签: emoji 图标（20px）+ 文字标签（12px）
安全区域: pb-24
```

### 7.7 顶部进度栏（任务页）

```
位置: fixed top-0
背景: var(--ln-color-surface) (#FFFFFF)
底部边框: 1px solid var(--ln-color-border-light)
进度条高度: 2px
进度条填充色: var(--ln-color-primary)
左侧: 返回按钮（icon + 文字）
右侧: 百分比文字
安全区域: pt-safe-top
```

## 8. 过渡动效

| Token | 值 | 用途 |
|-------|-----|------|
| `--ln-transition-fast` | `150ms ease` | 微交互（hover 色、按钮按压） |
| `--ln-transition-normal` | `250ms ease` | 标准交互（选中态、进度条） |
| `--ln-transition-slow` | `400ms ease` | 页面级过渡 |

### 动效原则

- 仅使用 `translateY(-2px)` 微上浮作为卡片悬停反馈
- 按钮按压使用 `scale(0.99)`
- 支持 `prefers-reduced-motion` 媒体查询，降级为近零时长
- **禁止**粒子效果、视差滚动、复杂动画

---

## 9. 图标

- 使用 **Lucide Icons** 图标库
- 全局使用 emoji 作为模块入口的视觉标识（而非自定义图标）
- 图标尺寸：导航栏 20px，按钮内 16px
- 图标颜色继承 `currentColor` 或通过 CSS 变量指定

## 10. 页面结构模板

### 任务驱动页面（种子发现、价值观、生命平衡）

```
[固定] 顶部进度栏
  ├── 返回按钮（左）
  ├── 标题（中）
  └── 百分比/步骤（右）

[可滚动] 主内容区
  ├── 页面标题（serif 居中）
  ├── 副标题（灰色小字）
  ├── 内容卡片（白底圆角边框）
  │   ├── 标签/步骤指示
  │   ├── 主体内容
  │   └── 操作按钮
  └── CTA 按钮（全宽药丸）

[固定] 底部导航栏
```

### 信息展示页面（首页、报告）

```
[可滚动] 主内容区
  ├── 页头区域
  │   ├── 品牌标识 + 标题
  │   └── 问候/描述
  ├── 信息卡片（多个）
  └── CTA 按钮

[固定] 底部导航栏
```

## 12. 对比：原方案 vs 新方案

| 维度 | 原方案问题 | 新方案改进 |
|------|-----------|-----------|
| **色彩** | amber + green + indigo + purple 多色混乱 | 单一琥珀金品牌色，统一中性色系 |
| **层级** | 深色 glass 与浅色 glass-card 交替，前景背景模糊 | 统一浅色方案：奶油底 + 白卡片 + 细边框 |
| **边框/阴影** | 部分无边框靠透明度区分 | 全部使用实色边框表达层级，禁用彩色阴影 |
| **圆角** | 2xl(24px)/3xl 混用，过于圆润 | 收敛至 6-16px，更克制 |
| **字体** | 衬线/无衬线混用无规律 | 标题统一衬线，正文统一无衬线 |
| **按钮** | 三种按钮在深/浅背景上行为不一致 | 统一交互态：悬停上浮 + 按压缩小 |
| **交互** | 选中态用紫/粉色渐变 | 选中态用品牌色边框 + 浅色背景 |
