Part 02

F18 国风妆造专栏（非遗创新创意开发赛道）

结合科技与创意，将传统妆容文化与现代 AI 技术结合，打造国风妆造专区。面向当下年轻人国风热潮（汉服、国潮美妆），实现非遗文化的数字化传播与消费转化。

2国风妆容专题库

按朝代与民族分类的妆容专题库，每个专题包含历史文化背景、妆容特征解析、经典元素提取，并基于用户面部资产进行 AI 适配。

2.1 朝代/民族分类体系

分类朝代/民族妆容特征经典元素适配脸型建议
唐代红妆唐代（618-907）饱满浓艳、面若桃花花钿、斜红、面靥、唇脂圆脸/鹅蛋脸适合饱满红妆
宋代淡妆宋代（960-1279）清雅素净、三白妆三白妆（额/鼻/下巴提亮）、修长眉长脸适合宋代修长眉形
明清素妆明清（1368-1912）端庄内敛、柳叶眉柳叶眉、樱桃唇、薄施粉黛方脸/菱形脸适合柔和线条
敦煌飞天妆敦煌（魏晋-唐）异域华彩、飞天神韵花钿、额黄、翠眉、丹唇心形脸适合飞天灵动妆
苗族银饰妆苗族银饰搭配、自然山野银角头饰、红唇、自然底妆各种脸型均可搭配银饰

2.2 专题内容结构

历史背景介绍

每个朝代/民族的妆容历史背景，包含时代审美特征、社会文化语境、代表性人物（如杨贵妃、李清照等）。内容由专业历史顾问审核。

妆容特征解析

拆解妆容的核心技法：底妆方式、眉形画法、眼妆特点、唇妆风格、面饰点缀。配合高清示意图与分步教程。

经典元素提取

提取可复用的经典元素（如唐代花钿、宋代三白妆），作为独立素材供用户自由组合搭配，支持 AI 自动适配面部位置。

AI 面部适配

基于用户 128 维面部特征向量，智能推荐最适合的国风妆容风格。如圆脸适合唐代饱满红妆，长脸适合宋代修长眉形。复用 F1 面部资产库能力。

设计要点：国风妆容专题库的内容由专业历史顾问 + 美妆专家联合审核，确保历史文化准确性与美妆实用性并重。每个专题的 AI 适配复用 F1 面部资产库的 128 维特征向量，无需额外扫描。

每个技艺配备传承人信息卡片，包含：

  • 传承人姓名与传承级别（国家级/省级/市级/县级）
  • 代表作品与从业年限
  • 传承谱系（师承关系）
  • 联系方式（经传承人授权后展示）

3.3 AI 互动体验

AI 京剧脸谱生成

用户上传自拍 → AI 生成"你的京剧脸谱"效果。基于面部特征匹配最合适的脸谱类型（生/旦/净/丑），支持一键分享到国风社区。

AI 花钿试戴

用户上传自拍 → AI 在额头位置叠加不同朝代的花钿样式（梅花钿/寿阳妆/金箔钿），支持位置微调与样式切换。

5国风社区

为用户打造国风妆容交流与展示的专属社区空间。

5.1 用户分享

  • 用户可发布国风妆容作品（汉服 + 妆造搭配），支持图文/视频格式
  • 自动打标：AI 识别妆容朝代/民族风格，自动添加标签（如 #唐代红妆 #敦煌飞天）
  • 支持"一键同款"：浏览他人作品后一键获取同款妆容模板（复用 F3 UGC 妆造库能力）

5.2 月度国风妆容挑战赛

  • 每月设定主题（如"复原宋代皇后妆"、"敦煌飞天创意妆"、"苗族银饰搭配"）
  • 参赛用户上传作品，社区投票评选月度最佳
  • 获奖者获得焕新值(GP)奖励 + 国风品牌联名礼盒

5.3 社区互动

  • 点赞/投票选出月度最佳国风妆容
  • 评论交流妆容技巧与心得
  • 关注国风美妆达人，获取灵感推送

6消费决策属性

国风妆造专栏作为生活娱乐赛道核心价值"消费决策"的延伸，复用已有能力并做国风场景化适配。

6.1 复用 F8 防踩雷能力

  • 国风产品口碑分析：复用 F8 产品防踩雷系统的口碑分析引擎，针对国风产品进行专项分析
  • 国风产品水军识别：复用 F8 水军识别算法，过滤国风产品虚假评价
  • 国风产品肤质适配：复用 F8 肤质适配分析，为国风产品提供适配度评分

6.2 国货品牌对比工具

  • 同品类国货品牌横向对比（如花西子 vs 毛戈平粉底液对比）
  • 对比维度：价格、成分、肤质适配、用户口碑、国风设计评分
  • 输出结构化对比报告，辅助用户消费决策

8F18 数据模型

8.1 guofeng_themes（国风专题表）

CREATE TABLE guofeng_themes (
    theme_id        BIGSERIAL PRIMARY KEY,
    dynasty         VARCHAR(50) NOT NULL,        -- 朝代/民族：唐代/宋代/明清/敦煌/苗族/维吾尔族
    theme_name      VARCHAR(200) NOT NULL,        -- 专题名称
    theme_type      VARCHAR(30) NOT NULL,         -- 类型：朝代妆容/民族妆饰/戏曲妆容
    history_bg      TEXT,                         -- 历史背景介绍
    feature_analysis JSONB,                      -- 妆容特征解析（结构化）
    classic_elements JSONB,                      -- 经典元素列表
    cover_url       TEXT,                         -- 封面图
    gallery_urls    JSONB,                       -- 图集 URL 列表
    face_shape_match JSONB,                       -- 适配脸型映射
    difficulty      SMALLINT DEFAULT 3,         -- 难度 1-5
    status          VARCHAR(20) DEFAULT 'active',
    sort_order      INTEGER DEFAULT 0,
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);

CREATE TABLE heritage_skills (
    skill_id        BIGSERIAL PRIMARY KEY,

    description     TEXT,                         -- 技艺介绍
    video_url       TEXT,                         -- 展示视频 URL
    image_urls      JSONB,                        -- 图文展示 URL 列表
    steps_data      JSONB,                        -- 分步展示数据
    inheritor_name  VARCHAR(100),                -- 传承人姓名
    inheritor_level VARCHAR(50),                 -- 传承级别：国家级/省级/市级/县级
    inheritor_works TEXT,                         -- 代表作品
    inheritor_years INTEGER,                     -- 从业年限
    inheritor_lineage TEXT,                       -- 传承谱系
    ai_interaction  VARCHAR(50),                 -- AI 互动类型：脸谱生成/花钿试戴/无
    status          VARCHAR(20) DEFAULT 'active',
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);

Part 03

F19 银发焕新模板（智慧助老赛道）

12适老化交互设计

针对银发群体的认知特点与操作习惯，提供 5 大适老化交互模式。

大字体模式

全局字号放大 1.3 倍。标题 22px → 28.6px，正文 16px → 20.8px，辅助文字 14px → 18.2px。按钮最小触控区域 48x48dp。可一键切换开启/关闭。

高对比度模式

增强文字与背景对比度。正文对比度 ≥ 7:1（WCAG AAA），标题对比度 ≥ 4.5:1。背景色从奶油底(#FFF8F0) 切换为纯白(#FFFFFF)，文字色加深。

语音优先模式

所有步骤支持语音播报（TTS），减少阅读依赖。语速可调（0.8x/1.0x/1.2x），音量独立控制。支持方言切换（普通话/粤语/四川话）。

简化操作流程

减少页面跳转，单页完成所有操作。步骤间无需返回上一页，采用纵向滚动式流程。关键操作增加确认弹窗，防止误触。

长按语音按钮

长按语音按钮持续听取指导（非点按）。松开即暂停，再次长按继续。降低老年用户的操作认知负荷，无需理解"播放/暂停"概念。

适老化原则：所有适老化模式均为可选开启，默认不开启（尊重用户自主选择）。首次进入银发专区时弹窗提示可开启适老化模式。

14健康安全

针对老年人皮肤特点，提供安全优先的产品推荐与镜面模式联动。

14.1 敏感肌优先推荐

  • 老年人皮肤屏障较弱，优先推荐温和/低敏/高保湿产品
  • 产品标签系统：标注"敏感肌适用"/"无酒精"/"无香精"/"无防腐剂"
  • 自动过滤含刺激性成分的产品（酒精浓度 > 5%、人工香精、强效防腐剂）

14.2 成分安全提示

  • 标注含酒精/香精/防腐剂的产品，并在详情页高亮显示
  • 提供成分解读（通俗语言，避免专业术语）
  • 与用户已知的过敏原进行匹配预警

14.3 简化版镜面模式

  • 与 F6 镜面模式联动，提供银发简化版
  • 保留：语音指导 + 截图对比
  • 去掉：AR 叠加效果（降低认知负荷）
  • 采用"左右对比"模式：左侧教程步骤图 + 右侧自拍截图
安全底线：银发用户的产品推荐必须通过成分安全审核。任何含强刺激成分的产品不得出现在银发推荐列表中，即使用户主动搜索也应弹出安全提示。

指标类别指标名称目标值测量方式说明
