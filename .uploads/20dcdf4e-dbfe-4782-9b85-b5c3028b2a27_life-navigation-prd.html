一、需求背景

1.1 业务背景与触发来源

生命导航应用源于望宏老师主内商学院的天国商业课程体系。望宏老师创立了一套完整的「天国商业课程理论」，涵盖时代观、宇宙观、人生观、世界观、经济学和新征程六大核心课程。课程通过撒商教育模式，帮助学员从信仰根基出发，重新审视生命方向、事业定位和人生规划。

作为课程课后作业，已有一个单页HTML原型Demo（移动端优先），包含7个阶段的自我探索流程：破冰对话、价值观卡牌、人生旅程地图、角色排序、愿景冥想、给未来写信、生命平衡自评，最终生成个人生命导航报告。本PRD旨在将这个Demo升级为一款完整的、可持续使用的生命导航产品。

核心课程体系
天国商业课程包含六大课程：天国时代观、天国宇宙观、天国人生观、天国世界观、天国经济学、天国新征程，形成完整的属灵认知与行动框架。

1.2 用户当前状态与痛点

🎯
方向迷茫

许多基督徒在职场和生活中缺乏清晰的使命感召，不知道如何将信仰与日常生活、事业选择有机结合。

📚
课程转化难

学员听完课程后，缺乏将课程理念转化为实际行动的工具和持续跟进机制，学习效果难以落地。

📈
成长无追踪

生命成长是长期过程，但现有工具多为一次性测评，缺乏「常用常新」的持续陪伴和成长追踪能力。

🌎
价值观冲突

世俗价值观与天国价值观的张力让许多人感到困惑，需要系统化的框架帮助梳理和锚定核心价值观。

1.3 如果不解决的后果

影响评估
  • 课程效果衰减：学员课后无法将知识转化为行动，课程影响力仅限于课堂期间，形成「听完就忘」的循环
  • 信仰生活脱节：基督徒的属灵生命与日常生活、职场事业长期割裂，无法活出「在地如在天」的见证
  • 生命成长停滞：缺乏持续的自我认知更新和目标检视，生命成长陷入「原地踏步」的状态
  • 课程体系价值未释放：六大课程和作业工具包（种子发现表、永恒画像、十年画像、年度计划）的深度价值未被数字化释放

三、产品定位与愿景

3.1 产品定位

生命导航 是一款 基于天国商业课程体系的属灵生命导航工具， 以信仰为根基、专业方法论为骨架、持续陪伴为灵魂， 帮助用户完成从「认识自我」到「超越自我」再到「规划自我」的全生命周期成长之旅。

3.2 差异化优势

⛷
信仰根基

以天国商业课程六大课程为理论支撑，每个功能模块都植根于属灵认知框架，区别于世俗的自我探索工具。

🔬
专业方法论

种子发现模型、Being-Having-Doing框架、OKR+PDCA闭环、全生命周期画像等专业工具，确保方法论的科学性和可操作性。

🌱
常用常新

不是一次性测评工具，而是持续陪伴生命成长的导航系统。日常灵粮、OKR追踪、PDCA检视、社区互动让用户持续回流。

3.3 核心理念

产品灵魂

「人生不是修行，而是绽放」—— 生命导航帮助每个人找到那颗神所赐的种子，浇灌它、培育它，让生命从内而外地绽放。

3.4 MVP范围与迭代方向

MVP阶段聚焦于将现有Demo升级为完整的「生命导航探索 + 种子发现 + 报告生成」闭环体验，验证核心价值假设。后续逐步扩展为包含日常导航、社区互动和AI智能导航的全功能生命成长平台。

模块A：生命导航探索 MVP核心

基于现有7阶段Demo升级，融入天国商业课程的核心元素，打造深度的自我探索体验。

A1. 种子发现四维评估

功能项描述优先级阶段
激情评估 通过情境选择题评估用户的激情所在：什么事情让你忘记时间？什么话题让你不自觉地兴奋？ P0 MVP
天赋评估 通过能力自评和他评，识别用户的天赋领域：别人常夸你什么？什么事情你学得特别快？ P0 MVP
天职评估 探索内心深处觉得「这是神让我做的事」的领域：什么事情让你有深深的使命感？ P1 MVP
事业评估 评估天职在现实中的变现可能性：市场需求、竞争优势、可行性分析 P1 MVP
四维雷达图 将四维评估结果可视化为雷达图，展示激情/天赋/天职/事业的匹配度 P0 MVP
种子类型判定 根据四维评估结果判定种子类型：激情型/天赋型/使命型/综合型，给出个性化解读 P1 MVP
交互逻辑说明

每维度包含5-8道情境化选择题，采用卡片式交互（类似价值观卡牌），每题限时60秒以捕捉直觉反应。完成后生成本维度得分，四维全部完成后汇总生成种子雷达图。支持中途保存进度，下次继续。

五、非功能需求

需求类别具体要求优先级
移动端优先 所有核心功能必须在移动端（375px-428px宽度）有良好体验；响应式设计兼容平板和桌面端 P0
数据安全与隐私 属灵信息高度敏感，所有数据端到端加密；支持本地存储优先，可选云端同步；符合个人信息保护法要求；用户可随时导出/删除全部数据 P0
离线可用 核心探索流程（7阶段评估）支持完全离线使用；数据在本地缓存，联网后自动同步 P0
PDF导出 生命导航报告支持导出为精美PDF，包含雷达图、种子画像、使命陈述等全部内容 P0
性能要求 首屏加载时间 < 2秒（3G网络）；核心交互响应 < 100ms；支持PWA离线缓存 P1
无障碍 支持字体大小调节（3档）；支持高对比度模式；满足WCAG 2.1 AA标准 P2
国际化 MVP阶段仅支持简体中文；预留多语言架构，后续可扩展英文、繁体中文 P2
隐私设计原则

生命导航涉及用户的属灵信仰、内心感受、家庭关系等高度敏感信息。产品设计必须遵循「最小采集、本地优先、用户可控」三大原则，确保用户的灵魂隐私得到充分尊重和保护。
