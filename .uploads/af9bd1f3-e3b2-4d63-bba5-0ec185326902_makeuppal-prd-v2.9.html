V2.9 变更概览（2026-06-26）

V2.9 是对 V2.8 的全局架构优化，基于 Demo V2.8.2.1（8375 行 HTML）中实际跑通的跳转逻辑进行 PRD 对齐。核心变更：底部 Tab 从 V2.7 的 5Tab 调整为 6Tab（新增"颜库"）、Onboarding 从 V2.7 的"注册→面部扫描→风格→渲染→会员"重构为"欢迎→肤质→扫描→风格→领奖"、首页金刚区重排、弹窗体系从零散定义升级为统一的 16+ 弹窗矩阵。

  • [REFACTOR] 底部 Tab 栏 6Tab 重构：新增"颜库"Tab（模板瀑布流），镜面 Tab 保持独立一级入口，商城升为一级 Tab
  • [UPD] Onboarding 5 步精简：取消注册表单步骤，改为欢迎→肤质→扫描→风格→领奖 GP，全程零强制填表
  • [UPD] 首页金刚区重排：5 宫格（镜面/局部搜索/商城/成分扫描/创作者），Banner 新增国风+银发双栏，热度榜+UGC 模板区落地
  • [NEW] 弹窗体系 16+ 规范化：统一 open/close 机制、遮罩点击关闭、弹窗分级（信息/操作/表单/全屏）
  • [UPD] 导航面板全面打通：F1-F23 全部功能映射到实际页面/弹窗跳转
  • [UPD] 成分扫描交互闭环：入口→拍照→结果→安全报告→+30GP 完整链路，任务联动
  • [UPD] 焕新值中心升级：等级展示+权益+任务三Tab+成就墙+兑换商城入口一体化
  • [UPD] 新增 6 个 API + 10 个埋点

V2.7 原有 5Tab（首页/搜索/商城/镜面/我的），Demo V2.8.2.1 调整为 6Tab，新增"颜库"作为模板浏览的独立入口。搜索不再是一级 Tab（在首页金刚区可直达），商城升为一级 Tab。

02 Onboarding 5 步精简

V2.7 的 Onboarding 是 5 步转化漏斗（问卷→注册→面部扫描→风格→渲染→会员弹窗）。Demo V2.8.2.1 简化为 5 步零填表流程，去掉了注册表单步骤，改为"先体验后注册"，降低流失率。

核心变化

V2.7：问卷→注册填表→面部扫描→选风格→AI 渲染→会员弹窗（6 步，注册是必经卡点）
V2.9：欢迎→肤质选择→3D 面部扫描→风格偏好→领奖 GP（5 步，零必填字段）

弹窗交互规范

  • 打开：所有弹窗统一使用 openModal(modalId) → 给弹窗 + 遮罩层添加 active class
  • 关闭：点击遮罩层（.modal-overlay，非内容区）自动调用 closeModal(modalId) → 移除 active
  • 嵌套：支持弹窗嵌套（如 gpCenterModal 内打开 ingredientScanModal 时先关闭父弹窗再打开子弹窗）
  • 分类：信息弹窗（无操作按钮）→ 操作弹窗（主/副按钮）→ 表单弹窗（提交/取消）→ 全屏弹窗（替换页面内容区）

06 成分扫描交互闭环

对齐 Demo V2.8.2.1，成分扫描从 F21 PRD 的"独立功能页"调整为弹窗式全链路体验，入口更前置、体验更轻。

交互链路

扫描结果区结构

  • 风险等级卡（risk-level-card）：三档——✅ 安全（绿色）/ ⚠️ 注意（橙色）/ 🚫 危险（红色）+ 一句话建议
  • 产品信息：产品名 + 品牌 + 敏感肌风险评分（环形进度条 0-100）
  • 成分分类（3 段）：安全成分（绿）+ 注意成分（橙）+ 禁用成分（红），每项列出具体成分名
  • 合规标签：🇨🇳 NMPA 合规 / 🇪🇺 EU 合规 / 🇺🇸 FDA 合规
  • 历史记录：最近 3 次扫描记录（时间 + 产品 + 安全等级）

任务联动

焕新值中心任务"🔬 成分扫描 1 次"（+20GP）的"去完成"按钮会 closeModal('gpCenterModal') 后立即 openIngredientScan()，实现任务→功能→任务完成的闭环。

07 焕新值中心升级

对齐 Demo V2.8.2.1，焕新值中心（gpCenterModal）从简单的 GP 余额展示升级为等级+任务+成就+兑换一体化中心。

焕新值中心结构

顶部 — 等级展示

  • 等级徽章 + 名称（如"银妆 Lv.2"）
  • 进度条（当前 GP / 下一级 GP，如 3500/5000 = 65%）
  • 等级权益列表（GP 加成 / 免费渲染次数 / 专属客服 / 生日礼包）

中部 — 任务 3Tab

  • 进行中：未完成任务列表，每项含图标+名称+进度条+奖励 GP+操作按钮（"去完成"/"领取"）
  • 已完成：历史已完成任务（灰化，"已完成"标签）
  • 成就：3×2 成就徽章网格（已解锁/未解锁状态）

底部 — 兑换商城入口

  • "🛍️ 兑换商城"按钮 → openExchangeMall()
