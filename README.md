# AI 拍照测肤系统

一个基于计算机视觉的智能皮肤分析系统，通过上传面部照片即可自动检测多种皮肤问题并生成专业的护肤建议报告。

## 功能特性

- 🔍 **人脸检测** - 自动识别图像中的人脸区域
- 🎯 **皮肤分割** - 精准提取面部皮肤区域，排除眼睛、嘴巴等非皮肤区域
- 🔴 **痘痘检测** - 检测面部痘痘、粉刺，评估严重程度
- 🟤 **色斑检测** - 识别色斑、黄褐斑、老年斑等色素沉着问题
- ⚫ **毛孔检测** - 分析毛孔大小和密度
- 〰️ **皱纹检测** - 检测面部细纹和皱纹
- ✨ **肤质分析** - 基于 GLCM 纹理特征分析皮肤质地
- 🎨 **肤色分析** - 评估肤色类型和均匀度
- 📊 **综合评分** - 多维度加权评分，全面评估皮肤状态
- 💡 **智能建议** - 根据检测结果生成个性化护肤建议
- 🌐 **Web 界面** - 美观易用的前端界面，支持拖拽上传

## 技术栈

### 后端
- **FastAPI** - 高性能 Web 框架
- **OpenCV** - 计算机视觉库
- **scikit-image** - 图像处理算法
- **NumPy** - 数值计算

### 前端
- 原生 HTML/CSS/JavaScript
- 响应式设计，支持移动端

### 核心算法
- **人脸检测**: Haar 级联分类器
- **皮肤分割**: YCrCb + HSV 颜色空间阈值分割
- **痘痘检测**: HSV 红色通道 + Lab 颜色空间 a* 通道
- **色斑检测**: Lab L* 通道 + YCrCb 黑色素检测
- **毛孔检测**: 霍夫圆变换
- **皱纹检测**: Blackhat 形态学 + 骨架提取
- **肤质分析**: 灰度共生矩阵 (GLCM) + LBP 纹理特征
- **肤色分析**: Lab 颜色空间统计

## 快速开始

### 环境要求
- Python 3.8+
- pip 包管理工具

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
python app.py
```

服务启动后，访问 http://localhost:8000 即可使用。

### API 接口

#### 健康检查
```
GET /api/health
```

#### 皮肤分析
```
POST /api/analyze
Content-Type: multipart/form-data

参数:
- file: 面部照片 (JPG/PNG)

返回:
- overall_score: 综合评分
- acne: 痘痘检测结果
- dark_spots: 色斑检测结果
- pores: 毛孔检测结果
- wrinkles: 皱纹检测结果
- texture: 肤质分析结果
- skin_tone: 肤色分析结果
- report: 完整报告（含护肤建议）
- result_image: 标注后的结果图 (base64)
```

## 评分体系

### 各项指标权重
- 痘痘: 25%
- 色斑: 20%
- 皱纹: 20%
- 毛孔: 15%
- 肤质: 10%
- 肤色: 10%

### 等级划分
- **优秀 (90-100分)**: 皮肤状态非常好
- **良好 (70-89分)**: 皮肤状态良好
- **一般 (50-69分)**: 需要针对性护理
- **较差 (0-49分)**: 建议咨询专业医生

## 使用说明

### 拍照建议
1. **光线**: 在自然光或均匀柔和的光线下拍摄，避免强光直射或逆光
2. **角度**: 正面拍摄，面部正对镜头
3. **妆容**: 建议素颜或淡妆，以便准确检测
4. **距离**: 保持适当距离，确保面部完整清晰
5. **背景**: 选择干净简洁的背景

### 注意事项
- 本系统仅供参考，不能替代专业医疗诊断
- 检测结果可能受光线、拍照设备等因素影响
- 如有严重皮肤问题，请咨询皮肤科医生

## 算法说明

### 痘痘检测
通过 HSV 颜色空间提取红色区域，结合 Lab 颜色空间的 a* 通道（红绿色度）进行联合检测，排除非皮肤区域后，根据面积和圆形度筛选真正的痘痘。

### 色斑检测
利用 Lab 颜色空间的 L* 通道（亮度）检测暗色区域，结合 YCrCb 颜色空间的黑色素敏感通道进行验证，有效区分色斑和其他深色区域。

### 毛孔检测
使用 CLAHE 增强图像对比度后，通过霍夫圆变换检测圆形的毛孔结构，根据密度评估毛孔粗大程度。

### 皱纹检测
采用 Blackhat 形态学操作突出细纹和皱纹，通过骨架提取细化皱纹，再根据连通区域的长度和面积判断皱纹的严重程度。

### 肤质分析
提取灰度共生矩阵 (GLCM) 的对比度、同质性、能量、相关性等特征，结合局部二值模式 (LBP) 综合评估皮肤质地。
