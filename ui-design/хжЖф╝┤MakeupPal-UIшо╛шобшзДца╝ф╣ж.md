## 二、全局设计规范

### 2.1 色彩系统

#### 2.1.1 品牌色

```css
:root {
  /* 品牌色阶 */
  --color-primary:          #C4956A;   /* 玫瑰金 — 主色 */
  --color-primary-light:    #D4B08A;   /* 主色浅色 */
  --color-primary-lighter:  #E8D5C0;   /* 主色更浅 */
  --color-primary-lightest: #F5EDE4;   /* 主色最浅 */

  --gradient-primary-v: linear-gradient(180deg, #C4956A, #D4B08A);
```

## 七、核心业务流程

### 7.1 AI 妆造流程

```
用户输入意图 → 扣除 GP → AI 渲染 → 生成 SOP 步骤 → 镜面跟练 → Before/After 对比复盘
```

| 步骤       | UI 表现                                       | GP 消耗 |
| ---------- | ---------------------------------------------- | ------- |
| 意图输入   | Chat 视图输入框 / 语音                         | 0       |
| GP 扣除    | 确认弹窗 "-50GP 确认渲染？"                    | 50      |
| AI 渲染    | 进度条 + 加载动画                              | —       |
| SOP 生成   | 步骤卡片列表（Free 用户仅显示前 3 步）        | —       |
| 镜面跟练   | 切换到 Mirror 视图，AR 叠加引导               | —       |
| 对比复盘   | Before/After 分屏对比，支持截图保存            | —       |

### 7.2 局部搜索流程

```
输入问题 → 扣除 GP → 展示解法对比 → 选择方案 → 跟练
```

| 步骤       | UI 表现                                       | GP 消耗 |
| ---------- | ---------------------------------------------- | ------- |
| 问题输入   | 搜索栏输入 / 语音                              | 0       |
| GP 扣除    | 确认弹窗 "-10GP 确认搜索？"                    | 10      |
| 解法展示   | 手风琴卡片展开，子卡片对比（难度/耗时/产品）    | —       |
| 方案选择   | 子卡片点击高亮                                 | —       |
| 跟练       | 跳转对应步骤教程                               | —       |

## 八、技术注意事项

| 项目               | 说明                                                         |
| ------------------ | ------------------------------------------------------------ |
| 图片格式           | 优先使用 **WebP** 格式，降级提供 JPEG                        |
| 安全区域适配       | 底部使用 `env(safe-area-inset-bottom)` 适配全面屏            |
| HarmonyOS 适配     | 适配 HarmonyOS 全面屏手势导航                                 |
| 面部扫描           | 需真机测试，MVP 阶段使用 Mock 数据                           |
| AI 数据            | MVP 阶段 AI 使用 Mock 数据，预留真实接口                      |
| GP 操作            | 所有 GP 消费/充值操作需实时校验余额                           |
| 动画时长           | 统一使用 0.2s ease（快速交互），0.3s ease（标准过渡）         |
| 滚动容器           | 所有水平滚动容器隐藏滚动条                                    |
| 文字截断           | 多行文本使用 `-webkit-line-clamp` + `overflow: hidden`       |
| 渐变实现           | 品牌渐变统一使用 `linear-gradient(135deg, #C4956A, #D4B08A)` |
| 毛玻璃兼容         | 同时写 `backdrop-filter` 和 `-webkit-backdrop-filter`        |
