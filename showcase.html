PROJECT OVERVIEW · 项目概述

让美妆不再盲目
让选择恰到好处

妆伴 MakeupPal 是一款面向亚洲女性的智能美妆助手 Web 应用，融合妆容推荐、教程学习、虚拟试妆、商品购买的一站式美妆体验平台。

我们以「AI 美妆闺蜜」为核心交互理念，通过面部档案分析、场景化推荐引擎、Tinder 风格滑动选妆、虚拟试妆预览与成分安全扫描，构建从「发现灵感」到「下单购买」的完整美妆决策闭环。

PRODUCT VISION · 产品愿景
「让每一位女性都能找到最适合自己的妆容，让科技服务于美，而非定义美。」
😣
妆容选择困难 海量妆容教程不知哪种适合自己，试错成本高
🧪
成分安全焦虑 敏感肌无法快速判断产品成分是否安全
📱
试妆体验割裂 看教程、试妆容、买商品分散在多个 App
💸
冲动消费浪费 买回不适合的产品闲置，造成金钱浪费

TECH ARCHITECTURE · 技术架构

分层架构 · 多端统一

妆伴采用清晰的分层架构，从表现层到数据层各司其职。同一套核心业务逻辑通过 Web、微信小程序、鸿蒙三端覆盖，最大化复用、最小化维护成本。

1
表现层 · Presentation
用户界面与交互
📱Web H5SPA 单页应用
💚微信小程序web-view 壳工程
🔴鸿蒙 ArkTS规划中
🎨玫瑰金设计系统CSS Variables
2
业务逻辑层 · Business
核心功能与交互
🎯推荐引擎8 场景算法
🎴Tinder 滑动20px 阈值 / 450ms 动画
🤖小美 AI语音唤醒 / 对话推荐
📸虚拟试妆拍照 / 实时预览
🔬成分扫描OCR + 安全评级
3
数据层 · Data
统一数据源与存储
🔗getLibraryItems()统一数据接口
💾localStorage本地持久化
📦12 数据模块商品 / 妆容 / 用户
🔄数据互通卡片↔瀑布流↔详情
4
工程层 · Engineering
构建与部署
📜原生 JS无框架依赖
🗃️单文件架构HTML + CSS + JS
⚙️PowerShell Server本地 HttpListener
🔧Git 版本控制makeuppal-partner 分支

Web H5
HTML5 · CSS3 · 原生 JavaScript
单文件 SPA 架构，无框架依赖，兼容主流移动浏览器，支持 iOS/Android/桌面全平台访问。
已上线 V3.6.0
💚
微信小程序
web-view 壳工程 · JSSDK
通过 web-view 嵌入 H5 demo，保留小程序原生分享能力，支持 localStorage 持久化与 SPA 导航。
已部署

鸿蒙 HarmonyOS
ArkTS · ArkUI
规划中的原生鸿蒙应用，将利用 ArkUI 声明式开发与分布式能力，实现跨设备美妆体验。

KEY FEATURES · 关键特性

八大创新点 · 技术亮点

从交互创新到架构设计，妆伴在每一个细节都追求极致体验。以下八大特性体现了产品的技术创新性与用户体验突破。

01
🎴
Tinder 滑动选妆
卡片式妆容浏览，左右滑动表达喜欢/不喜欢，20px 滑动阈值 + 450ms 弹性动画，让选妆像交友一样有趣。
02
🌸
小美 AI 美妆闺蜜
「小美小美」语音唤醒，1 秒响应，8 大场景智能推荐，支持对话历史与个性化记忆，真正的 AI 美妆顾问。
03
🔗
统一数据源
getLibraryItems() 统一接口，卡片模式与瀑布流模式共享同一数据源，确保跨视图数据一致性。
04
⏮️
回看功能
已浏览妆容可回看追溯，记录用户决策路径，支持撤销「不喜欢」并重新评估，避免误操作。
05
🔬
成分安全扫描
拍照识别产品成分表，自动评级安全性，敏感肌友好提示，支持拍照、相册、手动输入三种方式。
06
🎨
玫瑰金设计系统
高端美妆品牌视觉语言，#C4956A 玫瑰金主色，Noto Serif SC 衬线标题，16/24/32px 分层圆角，统一优雅。
07
📱
多端覆盖
Web H5 + 微信小程序 + 鸿蒙三端架构，单文件核心 + web-view 壳工程，最大化复用、最小化维护。
08
🔒
隐私优先
面部数据本地存储不上云，照片上传仅用于本地分析，3D 扫描调整为照片方案兼顾隐私与体验。
